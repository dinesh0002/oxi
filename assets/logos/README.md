# Logos

The SVG files here are copied from [Simple Icons](https://simpleicons.org) (version 16.36.0), once, into this folder. The site loads them from `assets/logos/` only: there is no runtime dependency and no external request.

- **Source:** Simple Icons, `icons/<slug>.svg`, checked against that release. Slugs: postgresql, mysql, sqlite, duckdb, clickhouse, googlecloudstorage, snowflake, databricks, googlebigquery, apachedoris, apachedruid, apachekafka, mqtt, ollama, anthropic.
- **Licence:** Simple Icons is released under CC0 1.0 Universal. Simple Icons notes that individual icons may have their own licence, so check the upstream project before reusing an icon elsewhere.
- **Not included:** Amazon, Azure, Microsoft, Power BI, Tableau, SQL Server, StarRocks and Apache Pinot have no icon in that release (or were removed at the owner's request). The site shows neutral text badges for them instead. Do not hand-draw or approximate a company's logo.

Trademarks belong to their owners. The logos identify the products that Oxi connects to; they do not imply endorsement.
