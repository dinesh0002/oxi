SSH

SSH tunnels

A database behind a bastion host can be reached through an SSH tunnel.

Form fields

Fill in the SSH host, SSH port (default 22), SSH user, and optionally a key file. Leave the key file empty to use ssh-agent. A key passphrase, if any, is stored in the keychain.

Host keys

  • The first connection through a new host shows its host-key fingerprint. Nothing connects until you trust that fingerprint.
  • If the host key changes later, Oxi refuses the connection and asks you to check it again.
